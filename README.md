# h13ce.github.io

Personal academic homepage of Binh Huy Nguyen.

## Current status

Structural v0 for the ERC-facing academic homepage. This version fixes the information architecture before custom visual design.

## Site structure

- `index.md` — landing page
- `research.md` — research overview
- `_research/` — five research-theme pages
- `publications.md` — publication layer
- `software.md` — research software
- `cv.md` — concise web CV
- `assets/` — bibliography and future visual assets

The current site uses the Minima Jekyll theme as a temporary structural base. Custom layout and styling will follow after the content hierarchy is reviewed.
